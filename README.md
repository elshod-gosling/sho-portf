## ⚡ Technical Features

- **Dynamic Bathymeter HUD:** Live tracking of elevation/depth (+18m to -10,928m), hydrostatic pressure (1.0 ATM to 1,093.8 ATM), solar lux, and oceanic stratum.
- **Continuous Ambient Canvas:** Procedural engine rendering golden sunset sparks, god rays, bubbles, bioluminescent jellyfish, and marine snow.
- **Procedural Web Audio Synthesizer:** Atmospheric audio (ambient ocean breeze -> underwater rumble -> whale sonar) with no external audio file dependencies.
- **3D Card Tilt:** Interactive glassmorphism cards responding to cursor movement.
- **Responsive & Print-Ready:** Optimized for mobile, tablet, desktop, and clean PDF/print resume output.

## 🌐 Deploy to GitHub Pages

1. Create a new repository on GitHub (e.g., `sea-portfolio` or `<username>.github.io`).
2. Link this local repository and push:
   ```bash
   git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**
   - Under **Branch**, select `main` / `/ (root)` and click **Save**
4. Within a few moments, your site will be live at:
   `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/`
